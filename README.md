# Fyspoti frontend

Windows music UI prototype. See docs/16-person-1-implementation.md for exact working features and integration limits.

With Node and npm installed:

1. npm install
2. npm run setup:desktop
3. npm run build
4. npm run desktop

For browser development: npm run dev. Full-track playback, downloads and cloud services are not connected. Real Apple catalog previews require network access. No Spotify credentials are required.
